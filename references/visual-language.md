# 画板手绘风格的视觉语言

本参考用于把口播变成可逐步看懂的手绘解释。目标是让观众感觉有人正在把问题摊开讲清楚：图形简单、物件熟悉、关系明确、能看到思路展开。成片不必真的在电子白板中录制，但需要保留这种解释过程。

## 证据与复现方案的边界

参考来源：[原分享链接](https://v.douyin.com/puHBpVakgaY/)；[对应抖音视频](https://www.douyin.com/video/7695775115769907577)。

现有核对能支持：真人矩形画面具有多种尺寸与位置；黑底图解出现物件隐喻、简笔图、文字和连接；右侧中文笔记按章节与章内要点推进；画面中有双语字幕；部分时间点能看到局部视口与整体图解的差别。

现有证据是多个离散时间点的页面画面核对，未完成原片连续播放及原文件下载。因此，不能把下列任何复现建议写成已确认的原片制作事实：逐笔绘制的具体方式、转场轨迹、笔画速度、音效落点、使用的软件和插件、作者实际工程结构。后续拿到可播放原片后可补充证据，但不能倒推成已确认事实。

## 默认外壳

默认先做 16:9 横屏，三个功能区是黑板、真人窗口、右侧中文笔记。它们不是三个恒定等宽的栏；真人通常嵌在左侧黑板区域内。上方可有短标题/章节进度，下方留同步字幕区。用户指定比例、已有版式或明确参考优先。

建议从以下可调参数开始，不将其当作原片像素测量结果：

| 参数 | 建议起点 | 调整依据 |
|---|---|---|
| 输出尺寸 | 1920 × 1080 | 投放平台、原素材清晰度 |
| 右侧中文笔记宽度 | 总宽 24%–28% | 中文行长与手机缩小后的可读性 |
| 黑板与人物活动区域 | 左侧约 70%–73% | 当前图解复杂度 |
| 区域间距与安全边距 | 画面宽度约 2%–3% | 避免人物、字幕和笔记挤在一起 |
| 顶部信息区 | 高度约 6%–9%，可省略 | 有无章标题与进度提示 |
| 底部字幕安全区 | 高度约 12%–16% | 中英双行及平台遮挡 |
| 小窗宽度 | 黑板活动区宽度约 24%–30% | 口型、表情与板书的平衡 |
| 中等人物窗口宽度 | 黑板活动区宽度约 32%–40% | 是否仍需看清人物交流 |

默认黑板使用近黑或深炭灰，笔记使用米白/暖白纸面。区分区域靠背景、留白和轻边界即可，不堆装饰。黑板中的画与字要像同一支笔画出来；右侧中文笔记保持清楚规整。若原素材与用户偏好需要白板或纸张，也可替换底色，并重新校验色彩对比度。

禁止通过横向压缩整套横屏版式来获得竖屏。竖屏需要重新分配黑板、人物与笔记的空间，重新检查每个语义时刻的可读性。

## 三种内容，各做一件事

| 区域 | 应放什么 | 不应放什么 |
|---|---|---|
| 真人 | 原话、表情、语气、经验与态度 | 为解释而编造的新发言 |
| 黑板 | 对象、过程、比较、分支、因果、障碍 | 整段口播抄写、大段小字 |
| 中文笔记 | 正在讲的要点、条件、结论、应记住的数字 | 逐字跟读字幕、未经支持的新结论 |
| 中英字幕 | 当前真正说出的完整语义 | 提前泄露下一段图解、碎片化单词闪烁 |

同一语句可以在三个地方对应为不同形式。例如口播说“产品能跑起来，离真正交到用户手里还有几道关”，黑板可以画“手机 → 三道门 → 用户”，笔记写“做出来 ≠ 完成上线”。这只是表达形式示例，不表示原片说过这句话，也不自动成为新视频的事实材料。

## 接地气的手绘图解

从观众认识的物件出发，再画抽象关系：

| 解释任务 | 可选物件/图形 | 应明确的关系 |
|---|---|---|
| 门槛、限制 | 门、墙、路障、锁 | 什么条件使路径受阻 |
| 发布、交付 | 包裹、手机、商店柜台、发射台 | 从谁手里到谁手里 |
| 成本 | 钱包、账单、硬币、计价条 | 一次性还是持续发生 |
| 时间、等待 | 日历、时钟、排队队列 | 等待由哪个环节造成 |
| 隐私、权限 | 收据、文件夹、钥匙、锁 | 谁收集、持有、能访问 |
| 审核、规则 | 清单、盖章、门卫 | 依据哪些明确条件 |
| 选择 | 分岔路、两扇门、天平 | 每个选项的代价与适用条件 |
| 结果回顾 | 路线图、清单打勾、终点旗 | 哪些问题已解决，哪些未解决 |

这些是图形词汇库，不是每段必填的模板。物件必须帮助理解，不因为“可爱”就加入。一个论点优先使用一个主隐喻；必要时扩展同一隐喻，不在同一镜中混入多套不相干的世界。

每个图解先写一句“观众看完应理解的关系”，再选图形。若删掉图形仍完全不影响理解，它可能只是装饰；若图形需要额外长篇解释，则应简化或换用更熟悉的物件。

### 笔触与形状

- 用简笔线条、略有不规则的轮廓、手绘箭头、圈线和短标签。可用 SVG、矢量路径或有授权的本地图形资产实现。
- 建议 1080p 下主轮廓线宽约 4–7 px，辅助线约 3–4 px；参数可调，最终以缩小后的实际导出为准。
- 不规则应事先固定。禁止每帧随机抖动线条或文字，让成片看起来晃眼。
- 一个图标用少量决定性线条表达，避免细碎排线、照片级材质和复杂透视。
- 文字少而具体：对象名、关键数字、动词、条件。箭头要有明确的起点和终点；存在条件时给连接标短标签。
- 可使用描边渐显、局部揭示、移动到位等手法建立顺序。可见的“手”与笔尖不是必需，不能凭空宣称原片使用了某种手写技术。

### 白、黄、红的功能

| 色彩 | 默认角色 | 使用限制 |
|---|---|---|
| 白/浅灰 | 对象轮廓、普通文字、基础关系 | 保持主信息清晰，不让所有元素同时抢眼 |
| 黄 | 当前关键词、推进方向、结果或正在讨论的数字 | 每个语义画面选少数重点 |
| 红 | 错误、阻碍、警示、划掉或需要特别注意的条件 | 不把普通过渡也涂红，不制造无根据的危机感 |
| 低亮灰 | 已解释的背景内容、暂时不关注的分支 | 不灰到无法读出其与当前内容的关系 |

不能只靠颜色传达判断；同时使用标签、线型、圈线、位置或符号。某一项目若改用品牌色，应保留这套语义分工。

### 字体与语言

- 中文笔记以清楚的中文字体为主，标题、当前项、旧项形成稳定层级。黑板标签可以更接近手写，但必须有完整中文字体覆盖。
- 不把参考中的英文板书当成必须英文的规则。图解语言由受众与主题决定，默认中文；专有名词可保留原文并解释。
- 数字只在有证据和必要条件时突出。单位、时间范围、样本条件不可因版面省略成误导。
- 建议 1080p 下黑板主标签 36–54 px，关键数字 54–88 px，右侧笔记正文 30–40 px。它们是起点，不是验收标准；实际导出缩至手机宽度后仍应读得懂。

## 真人窗口

默认保留真实拍摄画面的矩形边界，可使用轻圆角与细描边。不要默认抠像、替换背景、合成人物或改变其发言。仅在用户指定，或当前素材确有必要且处理可验证时使用抠像。

支持四种角色状态：

- `full`：人物占据左侧主体区域，适合开场明确观点、个人经验、态度与收尾交流。右侧笔记可保留。
- `top-right`：人物在黑板活动区右上，适合把主要流程和图解留在左侧及下方。
- `bottom-right`：人物在黑板活动区右下，适合上方图解或整体回顾。
- `middle-left`：人物在左侧中等窗口，适合在交流感与右侧局部图解之间取得平衡。

`full` 并不要求人物铺满整个成片。任何状态都应保护人物面部、口型、必要手势，并避开笔记和字幕。优先挪动图解或选择合适模式；不要为了腾空间把人物缩到难以感知表情。

源视频比例与成片窗口比例不同，应使用保留主体的裁切；禁止拉伸。若所有候选位置都压住关键图解，应重排当前图解，不能把遮挡留给观众。

## 右侧中文笔记

纸面区域位置稳定，内部信息分两层：

1. 章节层：编号、短标题、可选进度点，回答“整段视频讲到哪里”。章节数量由内容结构决定，不能固定成八章。
2. 要点层：已讲项低亮灰；当前项黑色加粗，并用红点等非纯颜色标记；未讲项可隐藏或降低显著度。章号不变时，要点仍可继续推进。

每条笔记对应一个完整要点。笔记更新由语义触发，不跟着每个字跳动。若内容超出安全区，先删减措辞或按要点分批显示，不缩成密密麻麻的小字。

保留此前几条的目的，是让观众知道论点累积到了哪里。不要在每句话结束后清空纸面，也不要提前一次展示整篇结论。跨章时保留何种上下文由内容需要决定。

## 字幕与最终可读性

默认准备中文、英文及双语字幕数据，并以中英双语呈现作为本风格起点；用户对语言和交付形式的要求优先。中英字幕按完整语义分组同步，英文是忠实翻译，避免逐词拆碎。字幕应与当前画板、笔记分工，不在三个区域复制整段同文。

所有制作的视频都落实[字幕关键词放大](subtitles-and-emphasis.md)：整条以普通字号和自然字距进入，到原声重点词才放大并带动邻字平滑让位，完成态保持至整条退出，下一条普通态重建。不能只变色或以板书/笔记大字代替；具体状态、实现与验收统一按该参考执行。用户明确保护字幕或只改其他区域时保留其范围并记录。

字幕区不得与人物嘴部或重要板书重叠。双语通常中文在上、英文较小在下，必要时调字号、换行与句段长度。平台 UI 安全区与播放器缩放需要在实际导出上检查。

第一帧即应能辨认人物/图解/笔记分工，前 3 秒呈现最强且真实有依据的钩子。可用一句话、一个明确问题、一个已支持结果或画面关系实现，不能用空白手写等待或品牌片头消耗开场。实际导出必须从 0–3 秒看到进入第一个完整观点，并正常速度听检；查看源文件、封面或静帧不等于完成此项。

最终验收还应查看手机缩小尺寸：是否一眼知道当前重点；人物是否挡图；笔记是否读得清；旧内容是否帮助理解；红黄强调是否过量。文件完整性检查不能代替观看和听检。

# 实现与验收

## 从计划到工程

本 Skill 的示意 HTML 用于检验构图和三路编排，不负责视频解码、音频混合或 MP4 导出。完整生产可用 HyperFrames、After Effects、剪辑软件或用户已有工程；不要宣称复制示意文件就已经完成视频。

以真实录音为主时钟，先完成原声精剪与源片到成片的映射，再对齐字幕和语义锚点。已有录像不需要重新录制才能分析/规划；缺必需素材时说明准确缺口，继续完成独立部分。

建议独立维护以下层，统一使用成片时间：

1. 黑色背景与顶部系列/主题栏。
2. 黑板视口：具有裁切边界的容器；其内部是一张可累计的知识地图。
3. 人物窗口：独立于黑板镜头的录像容器，圆角裁切；按状态变换位置与等比尺寸。
4. 中文笔记卡：固定屏幕坐标，章节、当前要点、已讲要点分别建模。
5. 底部字幕：完整语义组；默认中文大字、英文小字，用户需要时保留中/英/双语字幕文件；每片落实[字幕关键词放大](subtitles-and-emphasis.md)，保存普通初态、发声锚点、实时邻字让位与句末保持状态。
6. 声音：清楚主声、必要音效和配乐，分轨管理。

只变换黑板内部内容即可平移/放大局部；人物、笔记、标题和字幕不跟着该变换移动。需要总览时回到保留真实旧节点的范围，不能临时换一张内容不一致的总结图。

## 原声精剪先于字幕

已有真人录像先沿真实音画检查重说、卡壳、重复半句、重复修饰、无意义找词和废弃起句，选择最完整、自然的一次表达。重复内容必须从声音和对应画面时间线中实际剪掉，再对齐字幕；把字幕改短并不能修复观众仍听见的重复。

区分录制失误与有意强调：后一次只是修正、换词或重启同一句，且没有新增含义时可保留完整表达；为强调而重复、对比前后条件、解释操作差异或配合必要界面展示时则保留。不能机械删除相同词、所有语气词或所有停顿。保留否定、数字、限定、因果和说话者的观点强度，不拼成原声没有表达的新结论。

在可编辑工程记录保留区间和源片到成片映射。切口留足首尾音与自然气口，核对口型、操作状态和结果展示连续；重要的播放、等待结果或观察画面不因无人说话就被当作空白删掉。对转写标出的疑似重复回看原始片段，再检查所有实际切口及相邻完整句。未能实际听取时记录该限制，不把转写或自动删停顿当作原声精剪已听验。

## 手绘的三种实现

|方式|怎样实现|可如实称呼|
|---|---|---|
|路径描画|按实际顺序预先绘制 SVG/矢量路径；用路径长度驱动描边显现；笔尖可选，必须跟随当前路径端点|路径逐笔描画|
|文字显现|采用可读手写字体，按词/行遮罩或短淡入；重点用下划线、圈画或变色|手写字体、遮罩显现|
|真实画板录屏|保留实际书写过程，剪去无意义等待，按口播重排并记录速度变化|真实手写录屏|

文字描边逐笔需要字形路径或手写数据；普通文字元素不能靠横向裁切变成真实笔顺。不要每次渲染重新随机抖点：在建图时使用固定坐标，或固定种子生成一次并保存，确保跳转到任意时间都可复现。

颜色、笔刷粗细、动效长度都属于项目参数，不是已知作者参数。字体使用用户提供或可合法使用的字体，实际落盘到生产工程并保留其许可；检查中文字符覆盖与替换字体后的断行。手写字体尤其要实查 `≠`、`÷` 等比较符号与单位：缺字时改用意思明确的中文或支持该字形的字体，不能让否定、比较关系因符号消失而读反；在实际导出中复核。

## 计划数据

`assets/plan.example.json` 是小型构图示例，不是硬性视频结构：

- `kind`：`schematic` 表示无音画的示意；`production` 必须提供实际素材路径。
- `hook`：内容、依据、核心可理解时间与衔接；前置高光还记录预告角色、源片时间码、正文落点及答案位置，问题式预告不含答案。已保护开头的范围限制写在 `scope`。
- `elements`：稳定 ID、简笔图/关键词、坐标；`stroke` 显现需 `paths`。
- `chapters`：正文笔记标题和稳定条目 ID；章节数随内容。高光预告独立于正文，不占章号；其笔记标识为“精彩预告”或“本期高光”，正文从第 1 章开始。
- `beats`：语义段起止、说什么、口播锚点、板书保留/新增/移除、视口、人物模式、笔记已出现项和当前项、切换理由。
- `media`：生产输入；用项目相对路径，避免把凭据、私人素材或绝对个人路径提交到 Skill 仓库。

同一对象在各段使用同一 ID。需要重新显示时仍引用原 ID；不靠复制多张几乎相同的板书图模拟知识累计。真实精确到词的动作可在 beat 下扩展 `events`，记录 `at`、`duration`、`anchor`、`target`、`action`、声效与遮罩路径等。

字幕强调单独保留 `cue_id`、重点词范围、最终原声锚点、普通与目标字号、动作时长和完成态。整条先完整普通态；到锚点才放大，并依据当前可见宽度连续计算邻字位置；完成后到本条退出一直保持。英文层更新和分段初始化不得重置当前强调。下一条建立新普通态，不能继承上条缩放。计划检查器目前不检验这些行内排版与实际动画行为。

## 使用示意模板

在本 Skill 目录运行本地只读服务：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/assets/layout.html`，拖动时间条或选择语义段。示意图采用项目自造内容，不含参考作者录像、声音、标志或字体。人物框是明确的占位，不是假人物发言；模板没有自动播放与音画验收能力。

## HyperFrames 衔接

在目标环境读取当前安装的 `hyperframes` 入口，再按需要读 core、animation、keyframes、audio 与 CLI。入口不可用时沿用已有编辑器，或说明本次只能完成哪些层级，不假造工具运行结果。新环境不要假定同一绝对路径存在。

落地时：

- 以框架当前契约建立有尺寸的根合成，使用一个暂停且可任意定位的时间线；根 ID 与注册 ID 一致。
- 人物视频的移动/缩放作用于非计时包装层；视频源时间由框架管理。不要用自建 `play()`、定时器或回调累加控制媒体。
- 人物窗口和黑板相机是两组变换。笔记与字幕按各自时间区间显示，不能因黑板缩放改变屏幕位置。
- 对路径显现、文字显现、笔记切换和人物变换使用可定位到任意帧的明确初末状态；反向跳转后应恢复相同状态。
- 主视频保留原声时不重复挂分离录音；用分离原声时静音对应画面层。混音前检查实际输出，不能仅看标记。
- 命名动效或组件先查当前 registry，有适用组件再复用；没有对应效果时按实际需求实现，不能把近似效果说成原版。
- 按当前 CLI 做工程检查、关键时点截图、预览和导出；服从用户已有授权，不额外设定每片都要通过样片审批的门槛。

## 检查真实成片

工程校验通过后，对实际导出执行：

- 开头沿用[三秒钩子要求](choreography.md#前三秒与转入正文)，核对真实导出的首帧及约 0.5、1、2、3 秒，检查对象、主张和声音入口；0–2 秒只是早期检查点。以 1× 实际看并听 0–3 秒，连续至少 0–5 秒并到第一个完整观点结束，核对钩子在三秒内可理解、必要条件与正文自然承接，首词完整且无重复铺垫或口型错位。明确保护开头/局部编辑范围时保留并记录，不借验收扩大修改范围。
- 按[字幕强调验收](subtitles-and-emphasis.md#实际导出验收)检查普通初态、锚点前、放大中、完成、句末最后可见帧、退出及下一条初态；邻字平滑让位，无空槽、跳位、遮挡或提前回缩。再以 1× 看听代表片段，并核对随机跳转/分段导出的同一时刻一致。
- 按正常速度看过每次人物布局、画板观察范围和笔记当前项的切换前后。核对出场顺序和真实口播锚点，防止提前泄露、滞后补图或关键文字瞬间消失。
- 检查最密集、最小字号、最大缩放和笔记最多的状态；当前图解节点不被人物遮挡，字幕不压住底部必要内容。
- 检查所有主声接缝、音效落点和结尾，尤其是重说、卡壳、重复半句与重复修饰的删减处；检查完整原声而不只读精简字幕。确认没有重复铺垫、吞字、断气、意外改变含义或删掉必要操作。实际听取前不得标记“声音已验收”。
- 记录实看区间、方式和未检查项；局部抽查不能写成全片正常速度已观看。

无法实际听取时，只能记录已做的音轨/切口等检查，并标明主观开头及重读锚点听检未完成；转写、波形、播放器已打开和文件完整不能替代实际听检。工程检查通过、视听检查通过与发布后的留存改善是不同结论，没有发布数据不承诺降低跳出率。

制作记录用项目已有简短记录即可：钩子及来源、所用模式、素材与字体、实际检查、当前导出和用户选择。失败试片仅在确定废弃后进行可恢复清理；不要新建一批历史/审计文件。

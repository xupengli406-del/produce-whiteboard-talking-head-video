# 字幕关键词放大

本规范适用于本 Skill 制作的视频，与画板和右侧笔记共同执行。依据用户已确认的网感 V24 行内字幕衔接规则及本次明确的“所有视频都要字幕关键词放大”要求。它是用户制作规范，不能宣称是抖音参考作者已验证的工程做法或平台流量保证。

每片都应按真实原声选择值得强调的关键词/短语并落实可见的字号放大。不是每句话都放大，也不是逐字蹦跳。只变色、加粗、下划线，或只把黑板/右侧笔记做大，不能算完成字幕关键词放大。用户明确要求保留既有字幕或仅修改别处时，遵从范围并在制作记录中说明。

## 不可省略的状态顺序

| 状态 | 画面要求 |
|---|---|
| 整条进入 | 按该字幕条既定的语义分行完整显示；所有字包括重点词均为普通字号、自然字距。不能预留放大空槽、插空格或透明占位 |
| 重点词发声前 | 保持普通态，不能一出现就已经放大，也不能用下一句的锚点提前触发 |
| 真实发声锚点 | 以最终原声音轨的词/短语重读时点开始字号放大；颜色、形变可同时辅助，但不能替代放大 |
| 放大过程 | 根据重点词当前可见宽度增量，让邻字以同一动画进度平滑让位；保持读序与整句对齐，居中字幕的句子中心稳定 |
| 动作完成至退出前 | 保持放大及已选强调颜色/形态，不回到普通字号、原颜色或原形态，不在下一句到来前先缩回 |
| 整条退出 | 当前条整体按时退出；不能先去掉强调词留下半句 |
| 下一条进入 | 为新条重新建立自己的普通初态，不继承上一条的放大，也不提前处于强调终态 |

同条字幕有多个重点时，各自在自己的原声锚点进入，并维持已完成的强调至该条退出。若这会导致拥挤，优先按语义拆条或减少重点，不提前回缩前一重点“腾地方”。

## 时间与数据

以精剪后的最终原声为主时钟；改变剪辑后维护源片到成片映射并重新对齐字幕。自动词级时间可作为初稿，必须核对真实发声，保护否定词、数字、专名和完整短语。没有实际声音时只可标成建议锚点，不能声称精确同步。

字幕条除 `start`、`end`、文本、语言与分行外，建议保存：

- `cue_id`：稳定字幕条 ID；中英文共享语义对应关系但可独立排版。
- `emphasis`：目标文字范围或稳定 span ID、真实 `anchor`、动作时长、普通/目标字号或倍率、颜色、缓动、完成态。
- `layout`：普通态的实测字宽、当前动画宽度、整句对齐方式、固定语义分行和安全区。
- `source`：真实原声/字幕源时间；`review`：实际核对区间与未完成项。

普通字号的约 1.3–1.8 倍可作为试排起点，动作时长与曲线按原声、字体和版面调整。参数是建议，不能把某一倍率当成原片实测值或用极小变化敷衍“放大”。实际导出中应能明显感知重点，同时读得清整句。

## 实现邻字自然让位

先按最终字体测量普通态文字，保留正常字距。将重点与前后文字分成可独立排版的段；也可按字形实现，但不要为拆段插入可见或不可见的占位。

动画进度为 `p(t)` 时，重点的可见宽度从普通宽度连续过渡到放大宽度。用**当前**宽度重新计算相邻文字的位置，而不是使用最终宽度预留空间。居中时可令整行起点为“固定中心减去当前总宽的一半”，然后按当前宽度累计排布各段。这样左右文字会随重点增长平滑让位，整句中心保持稳定。

采用缩放变换时，原排版盒不一定随视觉宽度变化；必须另行更新占位宽度和邻字坐标，不能仅对 span 做 `scale()` 后让它覆盖邻字。采用可动画字号时，避免浏览器每帧自动换行引起跳动；先按语义确定行，再控制行内布局。双行字幕要检查放大后的垂直边界，不压住英文或下一行。

时间驱动应直接计算该时刻状态：锚点前为普通，动作中按进度插值，完成后到 `cue.end` 保持终态。不能依赖只执行一次的回调、播放历史或重新挂载时的默认初态。中英文可以分层渲染，但英文刷新、下一行初始化及分段导出不得重置仍然有效的中文强调。

本仓库的构图示意与计划检查器没有实现或验证这套行内字幕运动。生产工程需实际接入并导出；不能把文档或示意通过等同于动画通过。

## 与黑板、笔记配合

字幕忠实承接当前原声，黑板画关系，笔记留要点。一次语义重点可以联动，但应有主次：字幕放大时，黑板与右侧笔记优先稳定或轻量呼应，避免同时大幅缩放、换章与移动人物。

强调不是额外写一句更夸张的话。不得改写真实结论强度、删掉条件、把画面概括冒充原话。中英文翻译忠实；英文无需机械复制中文每个动作，但必须留出中文放大后的空间。用户要中文/英文/双语字幕文件时，保留共用最终原声时轴；SRT 本身不承载此动画，应在可编辑工程中保留强调数据。

## 实际导出验收

选实际使用了关键词放大的代表片段，覆盖动作前到下一条字幕，检查：

1. 普通初态、锚点前、放大中、完成态、句末最后可见帧、退出、下一条初态。没有预留空槽、提前放大、邻字跳位/重叠/被裁，完成后不回缩或回原色。
2. 最长中文、最长英文、双行、连续重点及字幕切换。手机大小仍读得清，不盖住嘴部、图解节点、关键证据或平台必要安全区。
3. 按顺序播放与随机跳转同一时刻，必要时对比分段渲染的同一时刻；字幕状态与位置一致。
4. 以 1× 正常速度观看真实导出，确认重点在原声重读处发生，邻字自然让位，句末保持到退出。连续帧检查只证明状态与排版，不能代替播放与听检。

将实际检查区间、检查方式和问题写回现有制作记录。若未能实际听取原声，标明发声锚点主观听检未完成；不能用转写、波形、文件完整或播放器已打开冒充通过。

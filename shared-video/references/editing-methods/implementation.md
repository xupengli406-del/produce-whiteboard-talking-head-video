# 实现与工具衔接

本库规定处理的目标、层级、时序和可见结果；具体工具在接到实际剪片任务时发现并核对。现有工程和用户工具选择优先，不把工具替换当成提升网感的必要步骤。

## 共享时间线

保留源片区间与成片区间的映射。剪掉停顿、重排片段或变速后，字幕、人物抠像、素材和音效统一引用成片时间。普通硬切让下一段从实际源片区间进入；定格独立记录取帧时刻、停留区间和此时是否仍有声音。

处理表写进已有工程说明或结构化时间线，字段按需要保留：

| 成片区间 | 源片区间/定格取帧 | 原声锚点 | 方法/配方 | 对象和动作 | 文字/声音 | 资产及参数 | 验收 |
|---|---|---|---|---|---|---|---|
| 按实际素材填写 | 可追溯到源片 | 实际说出的词或动作 | 例如 V11、R02 | 作用于画面/文字/前景/蒙版 | 原声及实际素材名 | 本次采用值 | 布局、运动、同步、声音 |

这是执行记录，不作为要求用户再确认的表格。只改局部时记录改动处即可。

## 剪映或其他时间线编辑器

- 先选择目标对象，再搜索预设。文字动画作用于文本；画面效果作用于对应视频片段；蒙版作用于上层视频或图形。
- 字体、动画和声音名称是原视频中的检索线索，本次版本是否有同名素材需要实际预览核对。
- 抠像层与底层的视频源、入点、出点、速度、关键帧和位置一致。前景仅做人物遮罩，复制层关闭重复音轨。
- 产品聚焦可用两份同步画面：底层压暗，上层保留亮度并加矩形蒙版。遮挡文字则把文字放在人物前景与底片之间。
- 定格先从真实表情取帧，再决定放大、颜色和标签；检查定格后恢复运动的切点。需要保留原声时独立延续音轨。
- 先验证素材卡片的完整运动和听感，再采用。找不到名称时使用同功能素材或手工关键帧，并记录替代。

## 代码或 HyperFrames 工程

实际制作先读取当前视频生产入口与工程规范。以下为处理关系，不是假定某个版本必有的 API：

| 目标 | 实现关系 | 必须验证 |
|---|---|---|
| 文字缩放/心跳/弹入 | 独立文本元素的 scale、位置和可见性关键帧 | 字幕锚点与动画区间一致，完成态可读 |
| 句内关键词放大（V24） | 以普通字号的整句排版为基准，按本次字体实际字宽计算关键词缩放产生的宽度增量；关键词变换与邻字位移共用进度/曲线 | 重点词发声前保持普通字号与自然间距；不用空格、透明占位或预设的大字宽度提前撑开句子，动作中无跳位、重叠或异常换行 |
| 向上露出 | 有裁切边界的文字容器＋子元素由下向上移动 | 容器不会误裁后续字幕 |
| 画面缩放 | 定时媒体片段内的视觉/裁切子容器变换＋明确变换中心 | 不变换负责播放时序的 clip；人物前景与底片同变换，边缘不露空 |
| 人物遮挡文字 | 底片、文字、动态透明前景分层 | 动态 alpha 真正来自对应帧；时间同步 |
| 圆形/矩形蒙版 | 容器 clip-path、SVG mask 或渲染器支持的 alpha 遮罩 | 输出渲染器与预览效果一致 |
| 局部保亮 | 同步底片压暗，上层原亮度画面经蒙版显示 | 明暗差不改变位置与产品颜色判断 |
| 硬切 | 区间切换和源时间映射 | 边界帧正确，音轨不重复、不出现空帧 |
| 定格与调色 | 取真实源帧为本地静帧，独立缩放、规范的媒体颜色处理与字幕层 | 定格期间没有视频继续走时造成漂移；声音是否延续另行记录 |
| 烟花/图标/扩音器 | 实际透明素材或可渲染图形层 | 不把编辑器缩略图直接当输出素材 |
| 声音联动 | 声音片段按成片时间入场，实际调整增益与淡入淡出 | 原声可听、声音落点正确、无突发尖峰 |

动态抠像需要真实的分割/抠像能力和逐帧或视频透明输出。工具没有此能力时先寻找本次可用的抠像路径；明确缺口和可实现替代，不能用普通矩形裁切声称已实现人物遮挡。

V24 可使用[行内字幕组件](inline-emphasis.md)复用终态与让位逻辑；V30／V31 按方法条目的步骤前提与真实坐标接入。动画参数在工程内保持可调。插入图片、视频、蒙版和文字后，以实际渲染结果确认它们使用的层叠顺序、裁切和混合行为。

### HyperFrames 的具体衔接

- 缩放与蒙版的动画作用于定时 clip 内部的视觉子层，例如 `.inner`；不能把负责时间窗口的 clip 当作镜头动画对象。
- 剪切区间使用当前 core 的源时间、开始时间和持续时间约定，恒速片段满足“消耗源时长＝成片时长×速度”。不能直接在普通播放回调里改 video.currentTime 来代替可寻址的时间线。
- 一个媒体对象或它的普通祖先中只保留一个定时窗口；不要在父层与 video 上重复声明播放时间。定格的任意中间源帧先预处理为本地静帧，不通过暂停实时播放器伪装可渲染定格。
- 抠像前景与底片放在同步变换组，配前景 alpha 依赖；文字层放在中间。原声独立时关闭复制画面的声音，每个混音 audio 都有稳定 ID。
- 声音和字幕素材按需读取当前 `media-use` 的音频与素材解析规范；此 Skill 的已授权声音联动无需每个素材重复询问。额外合成声音、收费或发送私有素材仍依本次权限执行。
- 调色与媒体效果使用本次工具支持的规范处理路径；HyperFrames 有对应媒体处理控件时先使用它，避免自制 CSS 滤镜造成预览与渲染不一致。
- 实际项目执行本次可用的 lint/check/render 命令；0 个样本或未运行的检查不能解释成已通过。外部技能与命令仍以使用时的当前文档为准。

## 检查动作

- 先看每组组合的开始、峰值、完成态及其后第一段普通画面，再按正常速度连续观看。
- 动态抠像重点查看头发、手指与越过文字的边缘；镜头变化时重新检查前景与底片。
- 检查主字幕和标签的出现、换行和消失；强调词应跟着实际表达，不提前或延后到下一句。
- 使用 V24 行内强调时，按[自然衔接规则](text.md#V24)核对初始态、锚点前、动画中、完成态、句末保持、退出与下一条初始态；顺序播放和随机 seek 都一致，不能只用大字完成态判定通过。
- 试听真实混音。素材名称正确不代表音量、长度或落点正确。
- 密集风格按用户参考验收。多个效果可以合作表达同一重点；优先解决具体问题，而不是机械减少种类。

# 联动组合配方

单项操作见详细库。本例的网感同时来自它们的先后与配合；同一表达重点可以使用多个方法，不把它们拆成互斥选项。下面保留完整关系，具体句子、时长与参数换成用户素材。

<a id="R01"></a>
## R01 开场报主题

- **来源：**约 0–1 秒。
- **组合：**V01 特黑体、V02 阴影、V04 文字放大、S01 上升音。
- **顺序：**先确定人物构图和短主题 → 标题开始进入 → 上升声配文字入场 → 留出清楚的标题完成态。
- **迁移：**开箱、测试、清单、观点视频的主题揭示。标题写本次内容，不照抄“8月开箱”。
- **验收：**第一眼能看懂主题，文字入场不会盖住本次人物重点；声音没有淹没首句。

<a id="R02"></a>
## R02 人物举手、大字遮挡与烟花

- **来源：**约 1–3 秒。
- **组合：**V05 向上露出、V06 心跳、V07 缤纷烟花、V08 画面缩小、V09 同步复制、V10 动态抠像、V11 前景遮挡文字、S01 上升音。
- **顺序：**建立同步双视频层 → 中层放第一部分大字并向上露出 → 画面缩小给举手动作空间 → 第二部分文字以心跳方式强调 → 烟花补充登场情绪 → 让手臂/人物真实遮住部分标题。
- **迁移：**用户视频中有举手、站起、指向或跨越标题的动作时使用。没有此类动作时可通过合适排布形成真实遮挡，不能伪造不存在的动作。
- **验收：**文字、人物前景和底片同时变化仍吻合；字被挡住后仍能理解；动画和烟花共同表达同一个重点。

<a id="R03"></a>
## R03 目标提示与重点推近

- **来源：**约 3–5 秒。
- **组合：**V12 画面关键帧放大、V13 扩音器、V25 语义图标、S02 集合哨声、S03 桌铃；字幕由 V01＋V02 过渡到 V01＋V03。
- **顺序：**目标句配小旗或对应符号 → 画面推近强调 → 后面的重点短语单独突出 → 为各自的重点安排提示音。
- **迁移：**宣布本期目标、给出结论、提醒注意。不同声音可分布在两个真实落点，不把两声机械叠在同一字上。
- **验收：**重点句与推近一致，符号帮助理解；字幕样式改变后仍保持整体视觉关系。

<a id="R04"></a>
## R04 圆形开拆后恢复常规画面

- **来源：**约 5–10 秒。
- **组合：**V14 圆形蒙版、V15 左上弹入、V26 斜向文字、V25 剪刀图标、S04 欢呼短音 → V16 拉框入屏、V03 描边字幕。
- **顺序：**圆形人物窗口与黑底形成分段 → “开拆”等行动提示斜向弹入 → 欢呼声配动作 → 恢复全画面和常规字幕，继续展示实物。
- **迁移：**进入实测、开始拆解、转到演示或下一组内容。“拉框入屏”具体运动需在目标工具预览后核对。
- **验收：**圆形与文字的边界不互相误裁；回到常规构图后没有遗留遮罩。讲述段保留看人物、读字幕和看实物的空间。

<a id="R05"></a>
## R05 从人物收束到产品局部亮点

- **来源：**约 10–13 秒。
- **组合：**V14 圆形窗口、V17 汇聚、S05 Ding → V18 矩形蒙版、V27 外围压暗局部保亮、V28 细节旁注、S06 综艺眨眼声。
- **顺序：**人物窗口收束并提示新信息 → 切入真实产品特写 → 通过明暗差突出讲到的部件 → 加短旁注 → 在细节提示的真实落点放短音。
- **迁移：**产品部件、界面按钮、实物纹理、具体数据区域；界面或证据展示时保留必要上下文。
- **验收：**局部窗口、旁注与所讲细节一一对应；亮区和底片吻合；标签不挡部件，声音不反复抢对白。

<a id="R06"></a>
## R06 程度词重音与自然硬切

- **来源：**约 13–16 秒。
- **组合：**V24 单字字号层级、V03 描边、V12 画面推近、S06 轻巧短音 → V19 硬切。
- **顺序：**程度词如“很”成为大字 → 画面在该语气处推近 → 本句落住 → 下一句通过硬切自然进入。
- **迁移：**程度、结果、感受或强调。只拆出用户真实说出的重点词；不要把大字改成更夸张但不真实的评价。
- **验收：**画面缩放与字号变化分别可控；切点保留说话完整性，后段构图自然。

<a id="R07"></a>
## R07 转折词、鼓点与购买反差

- **来源：**约 16–18 秒。
- **组合：**V24 转折大字、V12 镜头放大、S07 Tom鼓 → V19 硬切、S08 情绪音乐。
- **顺序：**“终于”等转折词配大字、推近和鼓点 → 后一句直接切入 → 音乐承接反差，为结尾包袱铺垫。
- **迁移：**真实的转折、结果揭示、预期落差。反差必须由本次视频实际内容支持。
- **验收：**鼓点与词语/画面共同落住；音乐进入不掩盖后一句；没有为了制造反差拼造新意思。

<a id="R08"></a>
## R08 定格调色与逐条标签包袱

- **来源：**约 18–21 秒。
- **组合：**V20 表情定格、V21 定格帧放大、V22 色度调整、V23 向右模糊 II、V29 逐条标签、V03 描边、S08 音乐。
- **顺序：**取真实表情并留住 → 放大重构表情焦点 → 颜色切换突出情绪段 → 标签逐条进入并累积 → 音乐延续到最后完成态，再自然收尾。
- **迁移：**幽默口播、自评、实测失误或轻松结尾；颜色、标签语气和条数由本次内容决定。
- **验收：**定格确实冻结，文字入场后变清楚；最后一条有阅读时间；标签不能冒充用户没有说过的个人事实。

## 密度与段落关系

本例开头和结尾变化集中，中段也有蒙版、字号和声音处理，同时保留普通讲述。复用其密度时先确认每组联动的表达重点与完成态，再根据实际观看调位置、时长和声音；不是先给每种技法设置固定的最低间隔。

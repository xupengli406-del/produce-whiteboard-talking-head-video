# 口播视频的视觉节奏检查

围绕语义、真实发声和当前操作目标调度注意力，检查重点是否清楚、证据是否可读、完成态是否稳定。技法与联动由主视频流程的内置方法维护；本参考用于按需检查，不另设频率或种类上限。

## 边界

- 本参考只负责口播视频的画面处理策略、动效密度与节奏验收。
- 不用动效掩盖内容问题。已有录制直接按实际声音精剪，指出具体重复或逻辑缺口并交给主流程处理；不因没有套 MG 稿件模板而停工、要求重录或退回审批。
- 不替代事实核验、原声合成、字幕校对、封面 Skill、平台发布或完整 MG 制作流程。
- 母版由调用主流程与用户选择决定。真人随手拍保留人物与现场，录屏/资料主屏才默认暖灰黑杂志版式；共同的[语义趣味、颜色角色与焦点错峰](visual-principles.md)由共同参考统一维护，检查时读取，不复制另一套菜单。明确换风格再调整；用户给出参考时保留有意强度与联动，按真实问题修正遮挡、错位和阅读不足。

## 开始前确认

至少取得口播稿或已对齐音频、语义时间窗、当前画面版本、目标平台和参考方向。先检查：

1. 每个语义窗只有一个主要传播任务。
2. 口播中的转折、结论、负面词、事实证据和空间关系已有发声锚点。
3. 当前问题究竟是“太平”“太乱”“重点不清”还是“证据不可读”。不要把四种问题都用增加动效处理。

只缺部分时间锚点时继续可确定的画面处理；涉及实质改变观点的缺口由主流程澄清。局部视觉返修不扩成整条稿件重审。

## 先建立稳定母版

在选择效果之前锁定长期不动的视觉骨架：安全区、字幕区、标题网格、主要内容区、色彩系统和证据容器。默认关闭持续漂浮、呼吸缩放、动态噪点、无意义光斑和全局背景运动。

母版跨越完整意思保持识别一致，内容变化时允许更新。不要仅为填满时间重置背景、构图、字号、颜色和运动方向。

## 按当前表达分配注意力

以 2026-10-15 用户确认的最新规则覆盖旧的固定频率、固定种类预算：

- 同一时刻只有一个主要注意力目标。
- 字幕、镜头、蒙版和声音可以联合表达同一个重点；尺度、位置、颜色等多维变化只要协调清楚即可，不一律拆开。
- 显著强调的间隔、技法种类和强度按语义、参考及可读性决定，不设“每几秒一次”或“全片几类”的上限，也不平均分配动效。
- 主要变化完成后至少保留一个可读完成态；证据和复杂关系应获得更长停留。
- 信息密集时优先减少无关竞争；复杂动作给足观看时间。清楚且有表达作用的强动作保留，不因“克制”机械弱化。
- “主画面太平、多个金框抢眼”分别按主维护处检查语义趣味、底／内容／注释／瞬时强调角色、峰值与旧标记退场。同色、多框或多动效不自动失败；不同色也可能抢焦点。先修对象与时序，不靠全删动作或把V24已落定强调提前还原来降噪。

## 选择处理方式

按语义需要选择，不按时间平均分配。详细方法、适用条件与禁用信号见 [处理方法](visual-rhythm-treatments.md)。

每个候选效果必须同时通过三问：

1. 它是否对应一个正在发声的关键词、状态变化、事实证据或空间关系？
2. 观众能否立刻知道应该看哪里？
3. 效果结束后是否留下清楚、稳定、可读的结果？

任意一问为否，修正具体的锚点、布局或完成态；无表达价值时删除该动作。

## 编排流程

1. 标记真正值得动的锚点：开头反差、核心转折、关键负面结论、官方证据、机制变化、最终结果。
2. 先为每个语义窗确定一个稳定完成态，再决定从什么状态进入它。
3. 生成“处理图”：时间码、口播短句、唯一焦点、所选方法、动作、完成态、最短停留和不用其他方法的原因。
4. 新组件或复杂联动先做覆盖一个完整意思的技术试片；已有实现和简单局部返修直接修改并复查，不强制新样片审批。
5. 以 1× 速度查看实际导出，分别检查静音画面和声画同步；反馈“吵、乱、不稳、看不过来”时定位具体竞争来源再处理。
6. 复查场景边界、效果前后和随机 seek；记录实际文件与检查限制，不将计划通过等同于审片完成。

## 验收门槛

- 随机暂停时，画面仍像完整构图，而不是动画半成品。
- 静音观看时，每个时间窗都能指出唯一焦点；不能同时有多个元素争抢视线。
- 声画一起看时，强调动作落在对应词语或语义转折上，不提前剧透，也不迟到补课。
- 连续两个显著变化之间留有感知与阅读时间；不存在为“保持动感”而重复抖动、放大或切背景。
- 证据截图在强调前后都可读；蒙版、圈线和放大不得遮字或破坏来源身份。
- 开头可以更强，但前三秒也只建立一个核心问题和一个视觉回报。
- 视觉效果不能新增口播未解释的观点、数字、规则或边界。

## 与完整视频 Skill 协作

完整视频 Skill 继续拥有脚本、事实、时间轴、声音、字幕、素材和交付决定；本参考提供焦点、阅读时间和过载检查。字幕强调与具体技法以 [内置剪辑方法](editing-methods/index.md)为准：V24 行内强调完成态保持到整句退出，V30 处理明确步骤，V31 跟随真实鼠标同位置聚焦。两者冲突时按用户最新选择及该方法的规范执行，不保留另一套弱化版本。

不要因为本参考 已执行，就宣称整条视频已经通过口播、声音、封面或发布验收。

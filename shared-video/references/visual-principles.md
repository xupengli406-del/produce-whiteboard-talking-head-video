# 语义动作、颜色与焦点

共同规则不指定画面主次，当前流程及本期已选构图优先。

## 每个场景写清四个阶段

在现有分镜／制作说明中，每场简记 **原话／素材来源、入场触发、此时展示目的、动作或关系变化的意义、必要持有条件、退出原因与下一步承接、完成态检查点**，实现于实际工程；多层组合按[网感执行流程](editing-methods/execution.md)记录对象与参数，不另建重复计划。每项可见信息与动作都应在这条语义线上有作用：观众知道为何现在出现、应看懂什么、为何继续留着或此时退出，而不是仅因套了模板就显示、移动或消失。

来源、目的和承接依据属于制作记录，不机械逐项变成画面旁注；观众只看此刻理解所需、具有独立观看价值的信息。只重复主强调或原字幕、没有独立用途的元注释应省去；真实引用所需的出处仍可按需保留，不全局禁用某个标签词。

1. **进入并识别。** 由实际发言、前一问、已有对象或上一结论触发进入，明确这一刻希望观众理解的重点；主对象先可辨，辅助项按发声跟进，后文标题不能仅因预加载就提前成为当前题目。运动方向帮助承接，不能独自代替语义联系。开头实际首帧应已有可理解的真实对象，不因全屏裁切或慢淡入先呈现空画布。
2. **停稳并阅读。** 关键资料和当前字幕落定，给足实际字量的阅读时间；持有取决于当前及后文是否仍需要这条信息。过去的推荐清单、标题或品牌不因曾出现就无差别叠留，无当前作用时撤去或降级，保证当前主次清楚；理解下一句仍需的条件也不能随换场乱清。稳定是可读的完成态，不是省掉后续呈现；不要在读长段时持续漂移或缩放。
3. **跟着意思变化。** 移动、放大、替换和关系变化分别对应当前重读、注意转移、对照或新结论，不为动而动。按本期已选表达，可让关键词接续、观看目标从全貌走向细节、证据被框选或比较差异被揭示；变化本身应帮助理解，不让无关装饰与当前重点争夺视线。字词原位接续、让位时，可见字宽与相应词间距一起连续变化，新内容未可见前不先挤出空槽；已有词的移动应能对应当下正在出现的内容。资料主屏时，真实材料或其观看位置也承担信息变化，不用无关旁标题包办全部动作。
4. **退出并交接。** 因本次强调已结束、条件改变、焦点转移或换题而退出，移走已无用的圈线、旧状态与标签；让仍有效的对象、短回指或必要前提接住下一句／下一话题。场景切换既不过期叠留，也不无差别全清。稳定外框与真人时钟继续，不用每次把全画布清空后重新搭一遍。

内容是否仍成立与某个动画是否结束分开判断。局部关键词或强调退场，不意味着上一套题目、推荐清单或品牌就应原样恢复；各层按当前话题、条件与后文依赖决定显示、持有和退出，避免过期信息在切换间隙“复活”。这同样适用于条件反转后的关系线和总结状态，不拿播放状态代替内容状态。

四阶段可重叠、合并于连续同图解读，时长依语义与阅读决定。不是每句换场，也不是每场硬塞所有特效。每场都要有可解释的视觉行为；确需只停稳阅读的段落，保留其阅读目的与前后承接。密度与强度按用户要求和实际输出决定，不设“每几秒一次”“只能两种”或统一弱化上限。

## 围绕当前问题组织关系

先确认这段在回答什么、哪些前文仍是理解它的必要条件，再安排真实资料和图形。关系表达同时落实两层，不能二选一：

- **动态解释层：** 按本期选定的文字、对象或资料表达，跟随当前问答、条件、理由、比较、选择或结论组织变化。文字可以通过关键词出现、大小与状态变化、替换、接续或并列对比承担表达；对象／资料也可在适用时呈现前后状态与反馈。主要信息的位置与身份稳定，变化把观众从前一个意思带到当前意思，不逐个堆满听到的名词。
- **固定提示层：** 动态解释讲完，在稳定、合理的区域留下后文仍需的少量当前问题、已给选择、条件或结论。固定层托住理解，不把动态演示再讲一遍；保留什么按后文依赖判断，不为凑数量堆卡片。后文补充、纠正或换题时更新、替换或退出，既不全部清空，也不全片累积所有关键词，不机械翻页。

两层配合时保持主次与信息位置清楚：动态层解释新关系，固定层安静保留必要上下文；没有后文作用的内容及时撤去。字幕关键词放大照常执行，与这两层关系表达分别验收。

**先服从本期已选的表达方式。** 文字动效可以直接承担逻辑和语气表达，不是只有具象物件、流程或操作演示才算完成。用户已选文字为主时，围绕原话用关键词入场、放大、替换、接续、留存或对比组织阅读；有助说明关系的箭头、连线、流程符号或简洁关系图仍可按需配合，不能从“不要具象演示”推断要无差别移除全部关系辅助或取消既有规范。文字落点规整、语义连续，不飞往各个角落、不整句累积，也不退化成反复清空的整页PPT。用户选择对象／资料演示时，再从原话确定适用对象、动作／条件、前后状态与反馈，决定哪些可见变化有助理解。不将某一次反馈推广成所有视频必须具象化或禁止演示；具体表达限制以当期明确选择为准，不用某个技法是否出现代替效果判断。

文字与图形变化都须忠于来源。采用自制图形时，它只是解释示意，不能伪装成官方界面、真实软件操作或产品已经完成的结果；不用虚构数值、性能条、进度或资源量来证明取舍，不把并列、比较、条件关系改成原话没有的因果。当前动态表达结束后再留下后文仍需要的少量固定上下文。已选全屏现场和人脸／字幕安全区持续受保护，不能为容纳说明层缩小真人或遮住交流。

| 原声关系 | 画面如何帮助理解 |
| --- | --- |
| 提问 → 回应、补充或不同意见 | 理解回答依赖前问时，保留一处简短的当前问题或必要前文；切到当前说话者／对应资料，让回应接回问题。对谈保留真实互动，人物身份和反应依据原片，不凭转写编造表情 |
| 条件／理由 → 选择或结论 | 让适用对象、必要条件与结论同屏或紧邻；理由随发声接到对应结果，不把有条件的回答拆成互不相干的口号 |
| 比较 → 取舍 | 共同维度与对象沿用固定位置，按原声切换当前项、连线或差异状态，留住会改变选择的条件；不靠产品名轮流放大代替比较 |
| 流程 → 下一步或结果 | 在稳定步骤骨架上推进当前阶段和连接，保留理解下一步所需的前置状态，完成后看得出路径；不每步清空后重搭一遍 |

同一个解释已经兑现后，用固定提示中的已讲状态或短回指承接后文，不再重复整套入场、同义字卡和关系说明；新增的条件、纠正、反例或不同意见仍要展开。原声中的冗余重说按[自然精剪](editing-and-audio.md#自然精剪)处理，不能只用画面遮卡顿。必要上下文不因视觉换场丢失；不要求每期都套问答、比较或流程的同一种结构。

## 有语义的趣味与惊喜动效

完整新剪辑默认主动从实际原声找个人判断、反差、发现、否定、揭示、完成、邀请等落点，并为适合的落点选择主画面的性格动作；不等用户再次要求“有趣”，也不把所有落点都处理成金色定位框。下面是扩展选项，不冒称认可预告全部用过，不要求每期红章或把菜单逐项用完。真实材料仍是主体，动作说明正在发生的意思，字幕可联动但不能独自包办全部变化。

关键包袱或原话中的提醒可用明显、幽默的短强调，在对应真实发声点进入，让观众看清此处语气；目的兑现后解释层回到正常表达，不把强刺激状态带入无关发言。具体是否盖章、颜色与强度取决于本期语气和用户选择，不设固定频率。画面注释不新增真人言论、争议或官方背书；“@”等视觉包袱不表示已发送消息或获得联系品牌的授权。解释层退场不改变字幕关键词按本句保持到退出的规则。

| 原声含义／选择条件 | 初态 → 动作 → 完成态 | 收尾与事实边界 |
| --- | --- | --- |
| **原话的关键包袱、提醒或个人判断：盖章** | 主画面与当前话意已明确→创作者短评印章在对应发声处从略大、略斜处落下，压实并短回弹→清楚停稳。可用朱红等区别于正文的注释色，大小与角度按舞台调整 | 文案依据原话和本人态度，不冒充官方认证、品牌回应／背书、作者原注或真实操作。落点避开人脸、字幕、证据与数字，并为入场最大放大／旋转后的完整外轮廓、描边与阴影留安全边距；不能只有落定帧完整。印章／纸签默认完整入镜，除非用户明确选择裁边效果；包袱或提醒结束后撤去，接回正常表达，不强留到下一无关话题 |
| **发现一个容易忽略的点、补充条件：纸条／手绘旁批** | 观众已看到对象→短纸条贴合、局部星芒或单条手绘笔势显现→旁批平整、记号静止，目标与解释一并读清 | 不满屏撒星或堆便签墙，卷角不循环抖；标注属于创作者解释，不能添加原声未支持的新事实，读完恢复资料重心 |
| **先卖关子再给答案：遮片／掀角揭示** | 先看清真实材料及待解释区域→遮片推走、纸角掀开或裁切窗打开→真实答案完整出现 | 只遮解释层或允许暂缓揭示的部分；不假装原网页发生互动，不隐藏读懂条件所必需的限定 |
| **预期与实际有落差：对照翻转** | 两个有依据的状态先建立共同基线→预期退后、实际以翻牌／替换／滑入接位→差异维度与结论落定 | 自制对照注明整理；金额、功能与结果来自真实材料，不用反转动效拼造因果或改原图像素 |
| **一大页里找到重点：抽出／聚拢** | 全貌可辨→当前原文段落以同源裁切抽出、其余线索退为语境→原段与上下文位置清楚 | 抽取部分保留出处与必要条件，不生成假引用；回到全貌或接下段时接住同一对象，不突然变另一份材料 |
| **材料多、要展开：纸叠／扇开** | 少量真实页面叠放→按讲述展开到当前页／并列来源→所讲页停稳成为重心 | 实际每页都有来源，不用一堆假页面暗示资料规模；看正文时停止扇动，其余页退为背景 |
| **明确排除、纠错或取消：划除／移出** | 正反对象可辨→对被排除项画一次叉／删除线或让其离场→保留实际选择 | 只对创作者整理层或清楚标明的注释操作，不把划线伪装成原作者改稿；否定与主语仍读得出 |
| **有路径、关联或交接：接力／接通** | 起点、终点与关系成立→线路绘出、节点接力或对象移动到对应位置→关系保持可读 | 动作指向实际关系，不给每个名词套框；结束后保持有效关系，撤掉无意义尾迹 |
| **原声有清楚数量或进度：积累／落位** | 真实数量与单位已核对→条目、页签、进度或数字按讲述落位→最终值稳定 | 数字变化只在明确自制说明层，最后与固定来源版本一致；不改网页计数、不把历史固定值滚成“当前最新” |
| **完成、解锁或收获：扣合／点亮** | 待完成状态清楚→元素扣合、勾选、翻开或结果点亮→完成状态留住 | 只有内容支持时才宣告完成，不伪造软件成功、授权、支付或平台发布状态；完成后不循环庆祝 |
| **语气有幽默反差：真实反应／定格包袱** | 使用本人实际表情或真实材料→短定格、适配标签或局部尺度变化→包袱落住后自然恢复 | 仅在本期语气适合时用，取真实帧，不用陌生人冒充本人；计划外不冻结正在解释的真人，标签不冒充其说过的新事实 |
| **有明确动作重音：弹性落位／有重量的停靠** | 真实图片、物件或完整短标题从可解释位置进入→一次有重量的位移／尺度／旋转衔接→回到稳定目标 | 弹性服务对象的空间变化；颜色与透明度趋于目标，不反复闪烁。强动作后给安静阅读，不让图片为填时长持续呼吸 |

参数从参考实际值或本次工具能力起步，以动作确实看得见、落点准确、完成态可读为准；不能用几乎不可察的缩放冒充趣味。出现“个人判断”时是新增创作者注释层，保持与官方页面／引用的视觉区别；没有对应语义时换适合的方法，不强塞印章、表情或庆祝。

## 调色角色与同屏焦点

母版由当前流程及本期选择决定；暖灰黑只是录屏/资料杂志风的默认，不是所有视频的底色。任何母版都不能被解释为“所有边框、标题、字幕、箭头都金色”。在同一现有制作说明中标出颜色角色、主焦点与旧标记怎么退场，再落到工程；这不是另换一套色盘，也不是限制全片最多几种颜色。

| 角色 | 用途与可选起点 | 不应承担的任务 |
| --- | --- | --- |
| **底色** | 暖黑、纸色或本期已选底色，稳定分区并托住资料 | 不持续变色、整图压暗或为了“动感”扫光；不改变人物和证据原貌 |
| **内容色** | 真实材料自身色彩、正文墨色／奶白；保住来源身份和常规阅读 | 不把截图原有蓝字、数据色或品牌色全改为金色来统一风格 |
| **注释色** | 导航、来源、关系线、旁批和已讲状态；按语义可用低饱和蓝、灰、柔金等，线重与对比低于当前主事件 | 不给所有信息套相同醒目框，不让导航、旁批和主证据同权 |
| **瞬时强调色** | 当前语气、结果或焦点的视觉落点；暖金可标重读，朱红可表个人态度／提醒，其他颜色按本题语义选 | 不是“红就错误／绿就权威”的自动判定；瞬时指吸睛动作阶段，不能借此让V24句内强调提前回色或回缩 |

**解决竞争先看任务和运动，再看颜色。** 同色不天然错误，多色也不天然清楚；多个框如果都高亮、同粗、同时弹入，就算改成几种颜色仍会抢视线。按当前语义采用以下策略：

- 主吸睛动作有清楚目标。指向同一目标的图像、字幕、圈线与声音可同步联动；侧栏／底层外框作为语境保持稳定，不与它同时各演一套。
- 从上一重点转向新重点时，旧注释框撤去、退为普通细线／低对比标记，或合并为一个共同括号；不能一路累积醒目金框。只处理后期注释，不擅改原图已有信息。
- 减弱的是后期框线、装饰与高光，不能连同正在读的原文字、单位、来源或必要条件一起压暗。需要表示角色时同时靠文字、位置或线型说明，不能仅凭颜色让观众猜。
- 比较任务确需多个框时，可以同色表示同一组、异色表示不同角色；让当前项先明确落位，其余项接力进入，之后一起静止供比较。不是禁止多框、多色或多动效，而是避免互不相关的峰值同时发生。
- 强弱错峰：先完成当前资料／对象的主动作，再让旁注、侧栏或下一项跟进；父容器已在移动时，子内容不再各自大幅飞入，父层落稳后再接子重点。完成态停稳后再开启下一个新的主吸睛动作；静态阅读可保留多层有用信息，不做循环脉冲保持兴奋。
- V24强调态仍按真实发声放大／变色并保持到整句退出。清理竞争时撤次要框、调整动作先后或降低无关注释对比，不能提前还原字幕强调来“腾焦点”。

原声锚点、目标对象、动作峰值、完成态、退场／降级点应在同一时间线可追溯。用户反馈“乱、多个金框、主画面没意思”时，分别检查任务、面积／线重／饱和度与时序：修正竞争、选择更贴切的性格动作，不能只换颜色、减掉所有动作或把文件改名为“丰富版”。

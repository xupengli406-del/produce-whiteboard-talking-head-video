# 真实资料与可见的语义动效

用户反馈“太平、没网感”时，先看实际导出中图形的尺寸、动作距离、状态变化与完成态。换一个库只能提高造型一致性，不能替代构图和编排。不要把“放了图标”当成动效完成。

## 完整口播默认执行的真实资料步骤

先完成“取得真实材料 → 来源可追溯 → 对齐发言 → 导出中确实展示”，再设计文字和图形。主动找真实资料、核对来源、附件对齐原声本来就是本流程要求；用户没有再次提醒不构成省略理由。

1. **按原声找材料。** 在现有分镜或制作说明中列出需要支撑的原声锚点与事实。介绍具体产品、项目、价格、功能、新闻事件、软件操作或文章内容时，主动搜索官网、官方仓库、官方发布／宣传物料、原始公告与文档、真实产品或应用界面；也使用用户附件和实测素材，不等用户逐张供图。官方材料不可得时，可采用来源可追溯的可靠报道并标明出处。
2. **取得后先核对。** 确认对象、型号、版本、日期与该句结论相符，保留原文件、来源链接、必要版本信息及素材哈希。宣传场景与本人实测分开，转引媒体图片保留实际图源和原水印；图片只支持其实际展示的事实。原图数字与本期口播版本不同时，保留原图并清楚标注版本，不能篡改截图来消除差异。
3. **真实材料优先上画。** 资料类型按本期内容与用户要求择用：辨认产品可用官方Logo、真实外观或产品首页，解释功能或效果的证据按需要选对应截图、真实界面／操作，讲报价用价格原页／发布会，讲目录或证据用真实目录／原文。不要求Logo、截图、界面三种全上。产品首次进入当前讨论时，在对应发声处实际展示已选的可核验材料；后续复提沿用位置与身份，不每次机械弹出巨大Logo。Logo帮助辨认产品，不冒充功能或效果证据；需要真实资料的地方，产品名标签、累积清单或关键词高亮不能替代实际材料。开头按[首帧规则](opening-and-retention.md)先让观众看见对象。已有合适材料时，不能用重画的纯文字卡、图标或复制原文的自制卡片替代。文字只承担必要标题、解释、圈线与补充；图标解释关系，不冒充产品长相或事实证据。纯观点可保留真人；确实没有合适真实视觉时，才使用明确标为“整理／示意”的概念图。
4. **逐句落实时间线。** 在同一分镜或制作说明记录原声锚点、素材文件及来源、所支撑的事实、进入／退出点、裁切和停留。按本期需要为产品标识、当前问题、比较项与来源等确定稳定、合理的信息位置与主次；同一对象沿用位置与身份，只在关系需要时移动或换位，不随每个名词四处飞入，未说到的产品不提前展示。动态解释与后续少量固定提示按[两层配合](visual-principles.md#围绕当前问题组织关系)落实。用户指定的附件逐一安排到实际讲述处；把图下载或复制进目录不算使用。数量依内容决定，不固定每隔几秒插图，也不照搬上一期的配图数量。横版图应保住关键文字和原水印；长图可在原生裁切窗口分段阅读，保留整张输入及裁切位置，不将整张缩成看不清的邮票。
5. **对照真正的导出验收。** 按锚点逐项看真实材料是否出现、与正在说的话是否对应、手机尺度下关键内容能否读完、进入退出是否清楚，以及是否遮住人脸或双语字幕。来源简注应可读且不抢主画面。先检查一段含普通口播与真实资料的短片，再检查整片所有素材时点；只有文字卡、占位或文件清单的项目不能记为“真实资料已完成”。

## 找库与选择

优先查看项目官方仓库、可用样例和 LICENSE。按本期语气挑一个主库，不因星数或“顶级”标签作选择：

- [Phosphor](https://github.com/phosphor-icons/core)：多字重和双色 SVG，适合生活、科技、人物互动等较亲和的叙述。双色部分可统一成一个强调色。
- [Lucide](https://github.com/lucide-icons/lucide)：统一线性图标，适合操作过程和工具说明。
- [Iconoir](https://github.com/iconoir-icons/iconoir)：较轻的几何线性表达，适合空间足够、画面清爽的片段；小屏粗细需实际检验。
- [lucide-animated](https://github.com/pqoqubbw/icons)：可参考对象局部运动。使用具体组件前查对应许可和使用限制；不要把网页 hover、循环或运行时回调直接搬进离线渲染。

把实际使用的 SVG 存入工程，记录仓库、固定提交/版本、文件名和许可证。只下载所需集合，保留授权文本；主库不要在同片里随意混成不同笔画、透视和填色。图标是示意，不是产品照片、真实产品结构或官方界面。

## 从名词变成关系

先写一句视觉动作，再选图标。例如：

| 口播含义 | 图标扮演的角色 | 可见变化与完成态 |
| --- | --- | --- |
| 远程看家 | 手机、家庭 | 两端先出现，线路接通，信号到达；连接态停留 |
| 跟随拍摄 | 拍摄者、相机 | 人先走，相机延迟跟上，最终保持距离 |
| 定制外壳 | 主体、画笔/外壳 | 外壳被选中、替换或从主体分离；修改对象清楚 |
| 未来做家务 | 灯、水杯、洗衣设备 | 随对应发声依次切换任务；持续保留“未来设想”范围提示 |
| 价格反差 | 预订、预期、公布价 | 预期与实际金额有明确替换/揭晓；最终金额稳定可读 |

不要给每个名词贴一个同时弹跳的图标。一个主要关系通常用一至三个对象表达；更多对象采用分步揭示。没有贴切图标时，用简单、有依据的自绘关系图，或保留真人表达。

## 构图、层级和运动

- 视觉主次服从当前流程与本期已选构图，借用真实资料方法不自动改成杂志版式。普通单人讲述可满屏，避免仅为放图标将真人缩小而留下无效空边；证据成为重心时可居中盖脸或铺主屏、真人入小窗。已选资料陪看保留其原片主屏；声音另按[引用声音状态](audio-state-and-mapping.md)处理；普通口播的“讲完恢复满屏”不覆盖该模式。小窗、双语字幕和资料不互相遮挡，不反复突然放大人脸。
- 图标要在手机尺寸辨认得出。人脸移动时复查图形跨过头发、皮肤和浅色墙面的对比度；必要时仅给功能标签加局部承托，不依赖静态背景上的一次对比度通过。以1080宽竖屏为例，主图标可从100–160像素比较，辅助图标可更小；这是起点，不是固定规范。真实预览中仍像小装饰就重新分配面积，不堆数量补救。
- 同一时刻只让一个主要关系发生变化。用位移、连接、局部旋转、替换或任务接力产生意义；外层统一淡入不能算对象自身动画。
- 形状、笔画、圆角和色彩成体系。强调色用于当前对象或结果；普通字幕保持稳定。无需把所有颜色、细节和动作都统一成一个机械模板。
- 按发声锚点进入，做一次明确动作，停稳供阅读，再退出。复杂动作分阶段，阶段间要能看懂结果。不要为了填满几秒重复抖动、呼吸、旋转。
- 数字不在随机金额间闪动；逐位揭示或滚动时检查遮罩，不能溢出半截数字。型号、金额、单位在完成态必须准确完整。
- 对近距离手持原片，动效优先落在图形和关系上。偶尔缩小真人腾出讲解空间可以，不要每个切口都做推拉或转场。

## 可复现与细查

使用当前视频框架的可定位时间线驱动动画。重复作用于同一对象的 fromTo 等动画要有确定初态，随机跳转、首帧和并行渲染应一致；不依赖鼠标、实时时钟或页面加载后才启动的循环。

较大返修先导出代表性短片，覆盖普通口播→重点图形→回到真人。确认尺寸、字幕、完整动作和退出都成立，再扩到全片。

最终检查实际编码文件：

1. 每个重点动作前、中、完成态和退出，确认入场看得见、无元素穿字、没有导出后静止。
2. 每个剪辑接缝的前后连续帧；区分说话找词、普通跳切、解码停帧与播放器缓冲。自动停帧/静音检测只报候选，不直接删掉所有停顿。
3. 检查真正卡住的语义：重复句首、重说词、同义绕回、接缝残留半个词。先修原声剪辑，再重新映射字幕和动效，不能靠大动画遮掉声音问题。
4. 开头、中段、结尾的音画映射和字幕锚点，防止变速后累计漂移。没有实际听觉能力时，不把转写、波形或无静音报告写成“完整试听通过”。
5. 用户反馈和实际视觉体验优先于工具通过。静帧对比证明构图，连续帧证明发生了变化；它们都不能单独证明1×播放节奏舒服。

## 录屏口播的操作与讲解

先按原声标出实际操作、等待、读结果、纯讲解。手把手教程的真实录屏是主体：点击、导航、输入，以及对当前提示词或结果的解说，都保留原界面和操作顺序。鼠标没动不等于脱离实操，不用抽象信息页盖掉用户录制的演示。重要操作即使无声也要保留，重复的口头表达可以静音处理，不能连操作一起删掉。

实际操作期间保留完整应用界面的全景底层；在真实鼠标或明确的当前讲解对象原位置做蒙版局部放大，建立全景、聚焦、停稳、恢复的过程，不另开固定放大窗口。只在有效目标处触发，不追随细碎晃动，不放大空白，不凭空补造点击；放大范围保留目标文字、按钮和上下文，副本与底层同源同钟。步骤入口可短暂用全屏文字蒙版，退出后返回实操，不把“全景持续可见”误解为禁止步骤切换。

具体执行使用[网感V31鼠标聚焦](editing-methods/picture.md#V31)。用户说出明确步骤、操作顺序或阶段切换时，按[网感V30全屏步骤文字蒙版](editing-methods/picture.md#V30)给当前步骤一个清楚入口；大字与蒙版退出后回到实际操作，不能用步骤页替换关键点击、提示词或结果。步骤名称与顺序依据真实内容，不凭空补流程。

无信息等待可收紧。仍在解释当前界面、提示词、执行状态或结果时，保留该真实界面，并通过原位置聚焦、高亮或下划线提示注意力。只有讲解确实脱离操作语境时，才切到相关证据或语义图形。信息画面必须有对象级动作和可理解的状态变化，不能只淡入一个标题后静止；按原声推进一次明确动作，停稳供阅读，不用循环抖动填时长。

用户附件逐一落实到时间线：原声句子、真实素材、进入点、停留、退出和导出检查点。播放量、私信、参考片段、提示词和结果视频各支撑对应内容，不相互替代；持续讲解可用真实资料加语义图形分步突出重点。补录按实际内容选择接入点，重新计算后续字幕及动效时间。

成片验收时实际看“操作开始→聚焦→结果→讲解画面→下一次操作”的完整往返，并复查每个附件在对应原声处确实显示、关键内容可读。精剪须检查重复句首、失败起头和找词；静音检测只处理已确认的空白，不能跨词任意切割或代替语义判断。

## 三种画面状态如何选择

| 表达任务 | 默认画面状态 | 必须保住的效果 |
| --- | --- | --- |
| 个人态度、铺垫、转折和连续讲述 | 真人满屏，按需直接叠加短图形 | 人物自然，没有为放图标挤出的大块黑边 |
| 需要观众看清一张真实图、型号、报价或细节 | 资料居中出现，可盖住脸成为重心 | 图片与原声相关，关键内容和水印完整，字幕可读，停稳后退出 |
| 需要持续阅读或解释真实资料 | 资料成为主画面，真人等比缩入辅助小窗；资料型横屏执行默认固定网格 | 主画面有明确内容层级；小窗脸部完整且不被资料或字幕盖住；回到纯口播时再恢复满屏 |

表中三种状态适用于普通口播的资料切换；陪看、持续录屏等可以按内容长期采用主屏加小窗，不被本表强制打断。品牌标识按需出现，不机械全片悬挂。资料型横屏的固定坐标与适用例外由当前流程自己的屏幕构图参考管理；图形、材料与停留按本期内容安排，不复制上一期内容，仍须看真实输出。
